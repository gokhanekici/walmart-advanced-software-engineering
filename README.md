# Walmart Global Tech – Advanced Software Engineering Job Simulation

My solutions to the four tasks of the **Walmart Global Tech Advanced Software Engineering** virtual job simulation on [Forage](https://www.theforage.com/).

Each task lives in its own folder, with a README explaining the problem, my design decisions and how to run or view the work.

| # | Task | Topic | Tech |
|---|------|-------|------|
| 1 | [Power of Two Max Heap](task-1-power-of-two-max-heap) | Advanced data structures | Java |
| 2 | [Data Processor UML](task-2-data-processor-uml) | Software architecture & design patterns | UML, PlantUML |
| 3 | [Pet Department ERD](task-3-pet-department-erd) | Relational database design | ERD, DBML |
| 4 | [Populate Database](task-4-populate-database) | Data munging / ETL | Python, SQLite |

## Skills demonstrated

- Implementing a custom heap with a focus on performance and edge cases
- Applying SOLID principles and design patterns (Strategy, Factory)
- Designing a normalized relational schema (supertype/subtype, junction tables)
- Writing a transactional ETL script that merges data from multiple CSV files
- Diagrams as code (PlantUML, DBML)
